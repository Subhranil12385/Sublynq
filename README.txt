SUBLYNQ — install-as-app files
Upload ALL of these to the SAME folder of your GitHub Pages repo (next to where index.html lives):

  index.html            (replace the old one)
  manifest.webmanifest
  sw.js
  icons/                (whole folder)

Then open the site in Chrome (https), reload once, and use ⋮ > Install app (or the in-app "📲 Install app" button).
If you previously added a shortcut, delete it first. Chrome > Settings > Site settings > "Clear data" for the site helps if it still says "cannot be installed".
